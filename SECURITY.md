# Security Policy

## Sensitive data

Never attach or commit `.env`, Telegram browser profiles, SQLite databases,
logs, screenshots, TLS private keys, or production configuration files.

If a Telegram browser profile or API key is exposed, revoke the Telegram Web
session from **Settings → Devices** and rotate the affected key immediately.

## Reporting a vulnerability

Please open a private security advisory in the GitHub repository. Do not post
credentials, session data, or exploit details in a public issue.
